# 综合计算工具

一个实用的制造业装箱与零件分板计算工具，整合了三种核心功能：

## 功能特性

### 1. 装箱计算工具
支持卷装和袋装两种计算模式：

**卷装计算**
- 自动根据轴承内径计算每箱最大卷数
- 支持按卷数或只数计算装箱方案
- 可选显示摆法示意图（可视化装箱布局）
- 内置内径-卷数完整对照表

**袋装计算**
- 支持按袋数或只数计算
- 自动分配整袋和零散零件

### 2. 零件分板计算
- 将零件均匀分配到多块电路板
- 可视化显示每板每层的零件分布
- 蓝色圆点●表示有零件位置
- 灰色圆点○表示空位
- 支持2-4板分配

### 3. 客户类型对照表
- 内置常用客户包装要求对照
- 支持模糊搜索（可省略横杠）
- 便于快速查找客户包装规格

## 使用方式

直接在浏览器中打开 `index.html` 文件即可使用，无需安装任何依赖。

## 页面结构

- **装箱计算工具** - 主要的装箱计算功能
- **零件分板计算** - 零件分板方案计算与可视化
- **客户类型** - 客户包装要求对照查询

## 技术说明

- 纯前端实现，无需后端服务
- 支持移动端访问（响应式设计）
- 所有数据在本地计算，保护隐私

## 开发环境

- 开发语言：HTML/CSS/JavaScript
- 样式风格：采用轻量级CSS，无外部依赖
- 浏览器兼容：支持现代浏览器（Chrome、Firefox、Safari、Edge）
